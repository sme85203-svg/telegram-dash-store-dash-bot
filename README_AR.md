# بوت متجر الشحن اليدوي

بوت تيليجرام لاستقبال طلبات شحن الألعاب والتطبيقات والبطاقات. **لا يوجد مزود شحن ولا تنفيذ تلقائي**؛ البوت يرسل الطلب إليك وأنت تنفذ الشحن يدوياً.

## التشغيل على الاستضافة

1. ارفع محتويات هذا المجلد إلى استضافة تدعم Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع ونفّذ:
   `npm install`
3. انسخ `.env.example` إلى ملف باسم `.env`.
4. ضع توكن البوت من BotFather في `BOT_TOKEN`.
5. ضع رقم حسابك الرقمي في تيليجرام في `ADMIN_ID` (وليس اسم المستخدم).
6. عدّل `STORE_NAME` و`PAYMENT_TEXT` حسب متجرك.
7. شغّل:
   `npm start`

## أوامر الإدارة

- `/addservice القسم|اسم الخدمة|السعر|تعليمات الطلب`
  مثال: `/addservice ألعاب|شحن لعبة جديدة|5000|أرسل رقم اللاعب والباقة`
- `/services` عرض الخدمات.
- `/orders` عرض آخر الطلبات.

أضف الخدمات والأسعار الحقيقية بنفسك. لا تضع بيانات سرية أو توكن البوت في ملفات عامة أو مستودع GitHub عام.

## ملاحظات مهمة

- الطلبات محفوظة في مجلد `data` بصيغ JSON. تأكد أن الاستضافة تحفظ الملفات بين مرات إعادة التشغيل.
- استخدم استضافة موثوقة، واجعل متغيرات البيئة سرية.
- البوت لا يستلم الأموال ولا يتحقق من التحويل تلقائياً؛ راجع الدفع بنفسك قبل تنفيذ الشحن.
